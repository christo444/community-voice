\section{TECHNOLOGY STACK}

\subsection{Backend Technologies}

\subsubsection{Framework \& Server}
\begin{itemize}
    \item \textbf{Flask 3.0.0}: Lightweight, modular web framework enabling rapid API development with minimal overhead. Chosen for flexibility in building three separate applications (main, admin, paralegal).
    \item \textbf{Flask-CORS 4.0.0}: Cross-Origin Resource Sharing middleware enabling secure communication between web frontends and backend APIs across different domains.
    \item \textbf{Flask-Mail 0.9.1}: Email integration module for sending credential emails, notifications, and system alerts via Gmail SMTP backend.
    \item \textbf{Gunicorn}: Production-grade WSGI HTTP server managing multiple worker processes for concurrent request handling and load distribution.
\end{itemize}

\subsubsection{Database \& ORM}
\begin{itemize}
    \item \textbf{Supabase 2.11.0}: PostgreSQL management ORM providing object-relational mapping, real-time subscriptions, and built-in Row-Level Security (RLS) policies for database-level access control.
    \item \textbf{PostgreSQL}: Enterprise-grade relational database with JSONB support for flexible schema design, full-text search capabilities, and built-in encryption.
    \item \textbf{python-dotenv 1.0.0}: Environment configuration management ensuring API keys, database credentials, and sensitive settings stored separately from code.
\end{itemize}

\subsubsection{Security}
\begin{itemize}
    \item \textbf{bcrypt 4.1.2}: Password hashing library using adaptive cost factors (salt rounds: 12), preventing rainbow table attacks and ensuring passwords remain secure even if database is compromised.
    \item \textbf{cryptography}: Advanced encryption standard (AES) for encrypting sensitive user data (PII, Aadhaar-related information) at rest.
\end{itemize}

\subsubsection{PDF Processing}
\begin{itemize}
    \item \textbf{PyPDF2 3.0.1}: Python library for reading, extracting, and manipulating PDF documents; enables initial text extraction from scheme PDFs.
    \item \textbf{pdfplumber 0.10.3}: Advanced PDF analysis library providing layout-aware text extraction with table recognition and coordinate mapping for accurate data parsing.
\end{itemize}

\subsubsection{Development Tools}
\begin{itemize}
    \item \textbf{pytest}: Unit testing framework for comprehensive backend test coverage and continuous integration.
    \item \textbf{black}: Code formatter ensuring consistent Python code style across the backend codebase.
    \item \textbf{flake8}: Linter checking code quality and adherence to PEP 8 standards.
\end{itemize}

\subsubsection{Localization \& Translation}

    \item \textbf{translator 1.0.0}: Multi-backend translation library enabling dynamic content translation between 8+ Indian languages without server-side dependency.
\end{itemize}

\subsubsection{UI Components}

    \item \textbf{google\_fonts 6.2.0}: Google Fonts integration providing consistent, modern typography across app with support for Indian language rendering.

\subsection{Technology Selection Rationale}

\subsubsection{Backend}
Flask was chosen for its lightweight nature and ability to create three separate applications without monolithic overhead. Supabase PostgreSQL provides enterprise-grade database capabilities with built-in security and real-time features. bcrypt ensures passwords are secure even if the database is compromised.

\subsubsection{Mobile}
Flutter enables single-codebase development for iOS and Android, critical for rapid deployment across platforms. On-device ML Kit OCR preserves user privacy by processing Aadhaar data locally. Voice plugins in multiple Indian languages ensure accessibility for non-literate users.

\subsubsection{Web}
React's component architecture and ecosystem maturity make it ideal for building responsive dashboards. Vite's fast build times accelerate development iteration cycles. React Router enables complex navigation patterns required by role-based dashboards.

\subsubsection{AI/ML}
Google Gemini's multimodal capabilities enable both PDF vision-based extraction and complex eligibility matching using natural language understanding. ML Kit OCR eliminates infrastructure costs and privacy concerns by processing locally.

\subsubsection{Cloud Infrastructure}
Supabase eliminates DevOps complexity while providing production-grade PostgreSQL, real-time capabilities, and built-in security. Supabase Storage integrates seamlessly with the database for file management.
