# Community Voice Platform

A voice-driven legal aid platform for marginalized and backward communities.

## Project Structure

This is a monorepo containing all components of the Community Voice platform:

- **`/mobile`** - Flutter mobile application (Android, iOS)
- **`/web/admin-dashboard`** - Admin web dashboard
- **`/web/paralegal-dashboard`** - Paralegal web dashboard  
- **`/backend`** - Backend API server
- **`/shared`** - Shared resources (docs, schemas, constants)
- **`/infrastructure`** - DevOps configurations (Docker, scripts)
- **`/supabase`** - Supabase database migrations and configurations

## Database

All platforms use Supabase as the shared database.

## Getting Started

Navigate to each subdirectory for specific setup instructions.
